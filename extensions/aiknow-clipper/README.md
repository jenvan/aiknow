# AiKnow 剪藏（Chrome / Edge 扩展）

解决一个具体问题：**公众号文章的卡片不能转发给 ClawBot**（微信「转发」列表里没有它），
所以手机上改用「转发 → 文件传输助手」这条原生路径，电脑上的网页版由一个扩展把链接
自动抽出来存进 AiKnow。

## 三条录入路径

| 场景 | 操作 | 需要 |
|---|---|---|
| 手机看到公众号文章 | 微信里「转发 → 文件传输助手」 | 电脑浏览器开着 `filehelper.weixin.qq.com` 并已登录 |
| 电脑任意网页 | 右键 →「存入 AiKnow 知识库」，或点工具栏图标 | 扩展已装、Key 已配 |
| 手机只有微信 | 「复制链接」→ 粘贴给 ClawBot | 上一阶段做的微信 bot |

## 安装（未打包扩展）

1. Chrome 打开 `chrome://extensions/`，右上角打开「开发者模式」；
2. 「加载已解压的扩展程序」→ 选本目录 `extensions/aiknow-clipper`；
3. 点扩展的「详细信息」→「扩展程序选项」，填：
   - **AiKnow 地址**：如 `http://192.168.1.x:8080`（手机/电脑都能访问的地址）
   - **API Key**：AiKnow 后台「密钥管理」新建，权限选 **读写**
4. 点「测试连接」，显示「连接正常」即可。

## 工作原理

```
手机微信 ──转发──▶ 文件传输助手 ──▶ filehelper.weixin.qq.com（网页版）
                                            │ content script 监听新增卡片
                                            ▼
                              POST /api/v1/articles/from-url
                                            │ 服务端归一 URL + 采集 + 去重 + 入队
                                            ▼
                              文章入库，AI 摘要/切片异步进行
```

卡片在 DOM 里长这样，脚本只取 `href` 和标题：

```html
<a class="msg-appmsg__content"
   href="https://mp.weixin.qq.com/s?__biz=...&mid=...&idx=1&sn=...&mpshare=1&scene=1">
  <h4 class="msg-appmsg__title">文章标题</h4>
</a>
```

## 两条必须保持的安全约定

1. **只发链接，不发 DOM**。页面里头像、封面的 `img src` 里带 `skey=@crypt_…`，
   那是网页会话凭据；把它发给服务端或打印进日志都等于泄露登录态。
2. **只自动收 `mp.weixin.qq.com`**。文件传输助手也会传文件、传别的链接，
   自动全收会把知识库塞满噪声。其它网页用右键菜单手动剪藏。

## 已知限制

- 网页版登录态会过期，过期期间的转发不会补录（没有离线拉取接口）；
  重新登录后脚本只会收「当前页面里仍在的」卡片。
- 页面结构由腾讯控制，改版会导致选择器失效；失效时脚本不会报错，只是不入库。
  排查方法：F12 Console 里搜 `[AiKnow]`。
- 同一篇文章转发两次：服务端按 `__biz + mid + idx + sn` 归一后去重（见
  `pkg/urlx`），第二次会回 409 并在卡片上标「= 已存在」。
